---
title: TypeScript Styles
description: A guide to writing TypeScript code in a consistent and maintainable style.
alwaysApply: true
---
 
- use camelCase for variable names. 
- prefer const over let. 
- Top level functions should defined using the function keyword. Any other functions should be defined using the arrow function syntax.
- Always use type annotations for function parameters and return values.
- Always use interfaces for object types.
- Always use type aliases for complex types.
- Always use enums for named constants.
- Always use type guards to check for specific types.
- Always use type assertions to tell the compiler what type a value has.
- Always use type inference to let the compiler infer the type of a value.
